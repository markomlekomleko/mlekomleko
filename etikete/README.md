# Etikete za flaše

Izvor: `etikete.html` (Montserrat, boje brenda; kravlje = teal, kozje = svetlo plava).
Izvoz: `node etikete/export.mjs` → `etikete/izvoz/` (PDF u tačnoj veličini + PNG 300 dpi + pregled).

Pre štampe proveriti: red "Flašira: Three & More d.o.o." i obavezne navode za sirovo mleko.
Mockup flaša (Higgsfield) su u `mockup/`; na sajtu su kao prvi slajd karusela.
